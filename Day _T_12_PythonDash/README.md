# Day 12 - Python Dashboard Integration

Final integration of the STM32 EV-ADAS system with a Python-based real-time monitoring dashboard.

## Features

- Real-time serial communication (UART)
- Live EV parameter visualization
- Battery SOC monitoring
- Accelerator position display
- Brake position display
- Motor temperature monitoring
- Fault code detection and display
- ADAS warning visualization
- Continuous data updates
- End-to-end EV dashboard integration
